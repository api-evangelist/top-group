# TOP Group (The Open Platform)

TOP Group (The Open Platform, [top.co](https://top.co)) is the tech company fueling the Telegram economy, connecting Telegram's audience to the TON blockchain through its two flagship companies: Wallet in Telegram (100M+ users) and TOP Labs, the venture builder behind Tonkeeper, TON API, Getgems, STON.fi, Notcoin, and Tribute. Founded by Andrew Rogozov, TOP is the first unicorn in the TON-Telegram ecosystem ($1B valuation).

Its developer surface centers on [TON API](https://tonapi.io) — the indexed REST, GraphQL, and webhooks API to the TON blockchain — with keys and rate-limit plans managed in [TON Console](https://tonconsole.com) and documentation at [docs.tonconsole.com](https://docs.tonconsole.com).

Backed by: ribbit-capital

This repository profiles the company's API surface for the API Evangelist network: OpenAPI specs for TON API and its Webhooks API, packages/SDKs, authentication, rate limits, sandbox (testnet), conventions, error catalog, lifecycle, webhook catalog, agent skills, and security posture.
