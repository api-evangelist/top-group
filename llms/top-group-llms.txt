# TOP Group (The Open Platform)

> The Open Platform (TOP, top.co) is the tech company fueling the Telegram economy, connecting Telegram's audience to the TON blockchain through Wallet in Telegram and the TOP Labs venture builder (Tonkeeper, TON API, Getgems, STON.fi, Notcoin, Tribute). Its developer surface centers on TON API (tonapi.io), the indexed REST/webhooks API to the TON blockchain, with keys and plans managed in TON Console. Generated by API Evangelist from the provider catalog on 2026-07-21; TOP publishes no llms.txt of its own (checked tonapi.io/llms.txt and docs.tonconsole.com/llms.txt, both 404).

## APIs

- [TON API](https://tonapi.io): Indexed REST API to the TON blockchain — accounts, transactions, blocks, jettons, NFTs, DNS, staking, rates, wallets, gasless, emulation. Base URL https://tonapi.io (testnet: https://testnet.tonapi.io).
- [TON API Webhooks API](https://docs.tonconsole.com/tonapi/webhooks-api): Manage webhook endpoints and subscriptions to account transactions, new contracts, opcode-matched messages, and mempool events. Base URL https://rt.tonapi.io.
- [TON API GraphQL](https://docs.tonconsole.com/tonapi/graphql): GraphQL endpoint at https://tonapi.io/v2/graphql (unstable; REST recommended).

## Specs

- [Cookbook](https://docs.tonconsole.com/tonapi/cookbook): TON/jetton transfers, NFTs, gasless, emulation, transaction tracking.
- [Pricing](https://tonconsole.com/tonapi/pricing): Plan-based rps tiers; free tier 1 rps, unauthenticated 1 request per 4 seconds.
